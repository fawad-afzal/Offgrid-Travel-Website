
# OFFGRID — Cinematic Luxury Travel Website

## Project Overview
OFFGRID is a fictional worldwide travel agency designed for Assignment #2 in Web Technologies, BSCS Semester 5. The website contains three linked pages: Home, Journeys, and Plan Your Escape. Its visual identity uses dark backgrounds, gold accents, destination photography, and elegant typography.

## What Is CSS?
CSS stands for Cascading Style Sheets. It controls the appearance of HTML elements, including colors, fonts, spacing, borders, and layouts. CSS improves readability, consistency, and the overall user experience.

For example, `p { color: #bac7ca; }` contains the selector `p`, the property `color`, and the value `#bac7ca`.

## CSS Methods
Inline CSS is applied directly to HTML elements using the `style` attribute. The home page uses inline CSS. Embedded CSS is written inside a `<style>` element in the HTML document's head, as demonstrated on the Journeys page. External CSS is stored in a separate stylesheet and connected using a `<link>` element. The booking page uses `style.css`. External CSS makes larger projects easier to maintain.

## CSS History
CSS1 introduced basic styling for text, fonts, colors, and spacing. CSS2 and CSS 2.1 expanded styling capabilities and refined positioning and media support. Modern CSS uses modular specifications and features such as Flexbox, Grid, responsive media queries, and advanced selectors.

## Browser Support and HTML
Browser support matters because different browsers can render layouts and form controls differently. Test this project in Google Chrome and Microsoft Edge, then record the actual results and any differences observed.

Semantic HTML elements include `<header>`, `<nav>`, `<main>`, `<article>`, and `<footer>`. A `<div>` is a non-semantic element used for generic grouping and layout.

## Testing and Deployment
Validate all three HTML files using https://validator.w3.org/. Test navigation, media playback, required fields, invalid emails, password length, age limits, and form reset behavior. Save validation screenshots and publish the completed project using GitHub Pages.

This project demonstrates front-end development only. It does not include a database or server-side booking system.
